# Module Handbook: Operational Research (5CM522), 2025/26

This folder holds the University's module documents for 5CM522 Operational Research, as provided for 2025/26. This README explains what the files are, what was changed before publishing them, and what a student should know that the files do not say.

| [Module Handbook Operational Research (5CM522) 2526.pdf](Module%20Handbook%20Operational%20Research%20%285CM522%29%202526.pdf) | The 2025/26 module handbook: module leader, schedule of work for both semesters, assessment. |

## What was changed before publishing

The text and layout of both documents are exactly as provided by the University. Only hidden metadata was removed:

- **Word document:** author, last-modified-by, company, revision count and print date were cleared; the sensitivity-label properties, the document-management (SharePoint) data and two leftover internal parts were removed. Word is set to strip personal information on future saves. The document body is byte-for-byte the original.
- **PDF:** the document information (author, creator, dates) and the embedded XMP metadata were removed. The page content is identical to the original.

Nothing in either file contains personal data of students. Staff names and e-mail addresses that appear in the visible text are the module leader's published contact details.

The visible "Sensitivity: Internal" footer and the cover image of the handbook were left as they are, because the documents are published unchanged.

## Review: things to know when reading these documents

### 1. The two documents disagree on assessment

| | Module Descriptor (approved May 2024) | Module Handbook 2025/26 |
|---|---|---|
| Components | One: coursework, 100% | Two: coursework 50% and timed in-class test 50% |
| Scheduled learning / independent study | 25% / 75% | 24% / 76% (48 of 200 hours) |
| Description | "applications of forecasting, planning and decision making" | "applications, for example, forecasting and quality control" |

The handbook is the document for the current year. Until the module leader confirms otherwise, follow the handbook: **coursework 50% + timed in-class test 50%**.

### 4. How the module mark is worked out

Module mark = 50% × coursework mark + 50% × in-class test mark.

*Illustrative example (invented student and marks):* coursework 62% and test 48% give 0.5 × 62 + 0.5 × 48 = **55%**. Whether that passes, and what happens after a failed component, depends on the pass mark and resit rules, which are not stated in these documents.

### 5. What these documents do not say (to be confirmed by the module leader)

- Exact coursework and test dates, and how to submit coursework
- How Coursework Parts A and B make up Component 1
- Pass mark, any pass mark per component, grade bands and resit rules
- In-class test: duration, sections, allowed materials and whether software may be used
- How to ask for an extension or report circumstances that affect your studies
- Material for the weeks marked "No folder yet"

If you are stuck or something affects your studies, contact the module leader named in the handbook as early as possible.
